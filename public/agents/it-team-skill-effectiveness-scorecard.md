# Effectiveness Scorecard

## When to Use

Use when you need to show whether the work is achieving its purpose, not just getting done.

## Steps

1. Restate the mission of the role in one sentence.
2. Choose one process measure, one efficiency measure, and one outcome measure. Start with the three in the agent file.
3. Record the current value, the target, and the data source for each.
4. Review the trend on a set rhythm, not a single reading.
5. For any measure off target, name the cause and one action.
6. Share the scorecard with the lead agent so it rolls up to the category view.

## Output

A three measure scorecard with current value, target, trend, and actions.
