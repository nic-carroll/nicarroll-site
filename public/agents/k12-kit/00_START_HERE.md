# Gemini Tool Builder Kit for K12

This kit gives school staff everything needed to build a working tool with Gemini inside Google Workspace for Education. No APIs, no connectors, no extra purchases.

## What is in the kit

1. `01_tool_brief.md` : a one page form you fill in before you prompt anything
2. `02_data_sheet_setup.md` : how to prepare the Google Sheet your tool will read
3. `03_gem_instructions.md` : instructions for an optional custom Gem that coaches builders
4. `04_build_prompts.md` : the prompts that build, refine, and check the tool in Canvas
5. `05_live_data_prompts.md` : the prompts and steps that connect the tool to a live Sheet
6. `06_publish_and_share.md` : publishing in Google Sites and the data owner sharing checklist
7. `07_version_notes.md` : what changes if your district pays for more Gemini access
8. `08_team_dashboard.md` : a full example, a shared team dashboard where each group edits only its own sections
9. `09_teacher_dashboard.md` : a full example, a personal elementary teacher dashboard with add, edit, and delete on everything

10. `10_keep_tools_alive.md` : how to build and share so a tool outlives the person who made it
11. `11_quiz_show.md` : a full example, a quiz game with Georgia Milestones item types tagged to Georgia standards
12. `12_station_rotation.md` : a projector board with stations, groups, and a rotation timer
13. `13_lesson_planner.md` : a week at a glance planner tagged to Georgia standards
14. `14_group_maker.md` : random picker, group maker, and seating chart
15. `15_mastery_tracker.md` : exit ticket scores by standard with reteach groups
16. `16_agenda_board.md` : a daily agenda for middle and high school teachers with several periods
17. `17_rubric_grader.md` : rubric scoring with class averages and a feedback prompt

19. `19_test_before_you_share.md` : ten checks to run before anyone else uses a tool

## The order to work in

1. Fill in the tool brief.
2. Set up the data Sheet and make a practice copy with fake names.
3. Open the Gemini app, turn on Canvas, and run the build prompts.
4. Test and refine until the tool does the job.
5. Decide: does the tool show student or staff records?
   * No: keep it as a snapshot tool.
   * Yes: run the live data prompts so the Sheet's sharing controls who sees data.
6. Publish in Google Sites.
7. The data owner sets sharing and tests with an account that should be blocked.
8. Record the owner, a backup person, and a review date.

## Three rules that never change

* Use your district Google account, never a personal one.
* Build with fake data. Real records go in only after the tool works and sharing is set.
* The person who owns the Sheet decides who sees the data.
* Every file lives in a shared drive, so the tool belongs to the school and not to one person.

## Which version am I?

* **Version A:** you have the Gemini app and nothing else. Everything in this kit works for you.
* **Version B:** you see a Gemini icon inside Sheets and Forms. See `07_version_notes.md` for shortcuts.
* **Version C:** you have Google AI Pro for Education. See `07_version_notes.md` for shortcuts.

Not sure? Ask your IT department which Google edition and add ons your account has.
