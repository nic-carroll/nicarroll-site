# Publish and Share

## Publish in Google Sites

1. Go to Google Sites with your district account and create a new site, or open an existing one.
2. Choose Pages, click the plus sign, and choose **Full page embed**. Name the page.
3. Add the tool:
   * **Live tool:** choose By URL and paste the Web app URL from Apps Script.
   * **Snapshot tool:** choose Embed code and paste the full HTML from Canvas.
4. Click Insert.
5. Click the share icon. Under Published site, choose **Restricted** and add named people or groups, or choose your district. Never choose Public.
6. Click Publish.

## Data owner sharing checklist

The data owner completes this, not the builder, unless they are the same person.

### Layer 1: the Sheet

* [ ] I am the owner, or the file is in a shared drive my team manages.
* [ ] The Sheet is shared only with named people or Google Groups.
* [ ] General access is set to Restricted.
* [ ] Viewers and commenters cannot download, print, or copy (Share, gear icon).
* [ ] Sensitive columns the tool does not need are on a separate tab or file.

### Layer 2: the tool

* [ ] The web app is deployed with Execute as: User accessing the web app.
* [ ] Access is limited to people in the district.
* [ ] No copy of the tool with real data inside it was shared from the Gemini app.

### Layer 3: the page

* [ ] The published Site is restricted to named people, groups, or the district.
* [ ] The Site is not public on the web.

### Test

* [ ] I opened the page as a person who should have access and saw the data.
* [ ] A person who should not have access opened the page and saw no data.
* [ ] I removed one person from the Sheet and confirmed the tool stopped showing them data.

### Keep it healthy

* [ ] Owner, backup person, and review date are recorded on the Sheet's About tab.
* [ ] The tool is listed in the district tool register.
* [ ] I review the sharing list at the start of each semester.

## About snapshot tools

A snapshot tool has its data typed or pasted inside it. Anyone who can open the tool can see all of that data, and it does not update. Use snapshot tools only for information that is fine for every viewer to see, such as a bell schedule, a room list, or totals without names.

## Sharing from the Gemini app

Sharing a chat or Canvas from the Gemini app sends a copy as it was at that moment. It follows your district's Drive sharing rules. Use it to show a colleague how you built something. Do not use it as the way staff reach a tool that contains records.
