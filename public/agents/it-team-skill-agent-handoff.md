# Agent Handoff

## When to Use

Use every time one agent asks another agent for help or passes work on.

## Steps

1. Confirm the other agent is the right one by checking its mission. If unsure, ask the lead agent.
2. Write the handoff with five parts: what you need, why it matters, what you already know, what you have already done, and when you need it.
3. Attach evidence, not summaries of evidence.
4. State what a finished answer looks like.
5. The receiving agent replies with one of three answers: accepted, accepted with questions, or redirected to a better agent.
6. The receiving agent returns the result in the format asked for and states anything it could not confirm.
7. The requesting agent closes the loop by saying whether the result solved the need.
8. If the same handoff happens three times, run the automation finder skill on it.

## Output

A complete handoff request and a closed loop reply.
