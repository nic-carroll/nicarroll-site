## Identity and Access Management

| Agent | Mission | Calls On |
| --- | --- | --- |
| IAM Analyst (`it-team-iam-analyst.md`) | Make sure the right people have the right access at the right time, and that access is removed when it is no longer needed. | IAM Engineer, Privileged Access Management (PAM) Administrator, Governance, Risk and Compliance (GRC) Analyst, Director of IAM, Security Analyst, SOC Analyst, IAM Architect |
| IAM Engineer (`it-team-iam-engineer.md`) | Build and run the systems that create, change, and remove accounts and that sign people in securely and simply. | IAM Architect, IAM Analyst, Security Architect, Security Awareness Coordinator, Application Security Engineer, Governance, Risk and Compliance (GRC) Analyst, Cloud Security Engineer, Security Analyst, SOC Analyst |
| IAM Architect (`it-team-iam-architect.md`) | Define the identity model, standards, and roadmap that let every system trust who a person is and what they should reach. | Director of IAM, IAM Engineer, Security Architect, Deputy CISO, Privileged Access Management (PAM) Administrator, Governance, Risk and Compliance (GRC) Analyst, Cloud Security Engineer |
| Director of IAM (`it-team-iam-director.md`) | Lead the IAM program so that access is secure, fast, and well governed, with a team that has clear scope and priorities. | IAM Architect, Deputy CISO, Governance, Risk and Compliance (GRC) Analyst, IAM Engineer, SOC Manager, IAM Analyst, Privileged Access Management (PAM) Administrator |
| Privileged Access Management (PAM) Administrator (`it-team-pam-administrator.md`) | Protect the most powerful accounts by vaulting credentials, limiting standing privilege, and keeping a record of privileged use. | IAM Engineer, Cloud Security Engineer, Application Security Engineer, Security Engineer, Security Analyst, SOC Analyst, Digital Forensics Examiner, IAM Analyst, Governance, Risk and Compliance (GRC) Analyst |

## Skills

| Skill | Use When |
| --- | --- |
| Process Improvement Review (`it-team-skill-process-improvement-review.md`) | Use when a task is slow, error prone, or done differently each time and you want a better way to do it. |
| Efficiency Audit (`it-team-skill-efficiency-audit.md`) | Use when you want to find where time, money, or effort is being spent without a matching result. |
| Effectiveness Scorecard (`it-team-skill-effectiveness-scorecard.md`) | Use when you need to show whether the work is achieving its purpose, not just getting done. |
| Agent Handoff (`it-team-skill-agent-handoff.md`) | Use every time one agent asks another agent for help or passes work on. |
| Automation Finder (`it-team-skill-automation-finder.md`) | Use when a task or a handoff repeats and you want to know whether to automate it. |
| After Action Review (`it-team-skill-after-action-review.md`) | Use after any incident, project, exercise, or task that did not go as planned, or that went unusually well. |
