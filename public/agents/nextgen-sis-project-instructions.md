# Working in this repository

* Before changing messaging, mass notification, email, text, voice, family opt outs or any outside connection, read `docs/CONNECTIONS.md`. It is the single source of truth, and the manual and the showcase page follow it. Update it in the same pull request as the code.
* Do not describe anything it marks Planned as working, in the app, the docs or a release note.
* Database changes only add (`docs/UPDATES.md`). Update `docs/COVERAGE.md` when a tool's level changes.
* Page text follows `.claude/agents/sis-ux-writer.md`: no dashes, no vendor names on screen.
