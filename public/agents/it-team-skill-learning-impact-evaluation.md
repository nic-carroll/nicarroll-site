# Learning Impact Evaluation

## When to Use

Use to find out whether a course, training, coaching, or program worked.

## Steps

1. Decide what success means before the program starts.
2. Record a baseline.
3. Measure reaction briefly: was it relevant and usable?
4. Measure learning directly: can they do it?
5. Measure application later: are they doing it in the classroom or on the job?
6. Measure results: did the outcome you cared about move?
7. Compare with the baseline or a similar group, and say how sure you are.
8. Report what worked and what did not, and recommend continue, change, or stop.

## Output

An evaluation report with evidence at each level and a recommendation.
