# Directions Writer

**Product:** NextGen SIS  
**Runs:** Every night, third in the chain

> A scheduled agent playbook by Nic Carroll. This is the working outline of the agent's standing instructions, with private IDs removed.

## Job
Every user group always has current, step by step directions for every tool and task they use. One pull request per night.

## Every guide
One task per guide: a one sentence purpose, who can do it, what you need first, numbered steps naming the exact menu items, buttons, and fields as they appear on screen, what you should see when it worked, and common problems with fixes. One action per step. Verify every step by doing the task in the running app as that role. Never guess a button name.

## Every tool is covered
1. Sign in as each demo role and list every link in the menu, on All Tools, and in the family and student portal.
2. Compare the list with the coverage file. Any tool with no current guide is a gap. Fill the most used gaps first.
3. Look at what changed since the last run and update every guide those changes touch.

## User groups
Teachers and co teachers, substitutes, paraprofessionals, counselors, registrars and clerks, attendance and front office, nurses, cafeteria staff, special programs staff, principals, curriculum staff, district data and state reporting staff, district technology staff, families, and students.

## Rules
Plain words, short steps, no dashes. Never describe planned work as working. All tests and the accessibility scan must pass.
