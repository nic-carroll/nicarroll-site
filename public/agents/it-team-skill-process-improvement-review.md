# Process Improvement Review

## When to Use

Use when a task is slow, error prone, or done differently each time and you want a better way to do it.

## Steps

1. Name the process, its trigger, and its finished result in one sentence each.
2. List the steps as they are really done today, with who does each and how long it takes.
3. Mark every step as adds value, required but adds no value, or waste.
4. Find the handoffs and waits. These are where most time is lost.
5. Ask the agents who own the neighboring steps what they need from this process. Use the agent handoff skill.
6. Propose the new process: remove waste first, simplify second, automate third.
7. State the expected gain in time, errors, or risk, and how it will be measured.
8. Name the owner, the first step, and the review date.

## Output

A one page before and after process map with expected gain, owner, and review date.
