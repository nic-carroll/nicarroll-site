# Gemini Tool Builder Playbook: Know Your Access

> Part of the Gemini Tool Builder Playbook for K12 by Nic Carroll. For staff using Google Workspace for Education. Practical guidance, not legal advice. Your district privacy lead owns the final reading of FERPA and state law.

Same tool, three ways to get there. Paid Gemini access removes manual steps. It does not unlock the pattern. Ask IT which version matches your account, and check again each semester because Google changes these often.

## Version A: Gemini App Only (Most Districts)

Education Fundamentals or Standard, no add on.

* Build in the Gemini app with Canvas
* Clean the Sheet by hand with a check prompt
* Copy Apps Script code into the Sheet yourself
* Paste errors back into Gemini

## Version B: Education Plus or Teaching and Learning

You see a Gemini icon inside Workspace apps. Shortcuts in Sheets and Forms.

* Everything in Version A
* Gemini side panel cleans and summarizes the Sheet
* Gemini drafts the intake Form

## Version C: Google AI Pro for Education

An add on license, often for central office staff. Shortcuts in the code editor.

* Everything in Version B
* Stronger models and higher limits
* Gemini writes and fixes code inside Apps Script (beta)
