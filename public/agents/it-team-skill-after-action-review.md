# After Action Review

## When to Use

Use after any incident, project, exercise, or task that did not go as planned, or that went unusually well.

## Steps

1. State what was expected to happen.
2. State what happened, with times and facts only.
3. List what went well and should be repeated.
4. List what did not go well and why, focusing on process and tools, not on people.
5. Invite every agent that took part to add its view.
6. Turn each lesson into an action with an owner and a date.
7. Update the playbook, standard, or agent file that the lesson changes.

## Output

A short review with lessons and tracked actions.
