# Automation Finder

## When to Use

Use when a task or a handoff repeats and you want to know whether to automate it.

## Steps

1. Describe the task, how often it happens, and how long it takes each time.
2. Check that the steps are stable and the inputs are consistent. If not, fix the process first with the process improvement review skill.
3. List what could go wrong if it ran with no person watching.
4. Decide the level: full automation, automation with a person approving, or a checklist only.
5. Keep a person in the loop for anything that removes access, deletes data, blocks a user, or cannot be undone.
6. Name the agent or team that would build it and hand off the request.
7. Measure hours saved after one month.

## Output

An automation recommendation with level, risk, builder, and expected hours saved.
